개요

마스크 감지·퍼스널 컬러 진단·가상 메이크업을 통합한 AI 뷰티 솔루션으로, 결과 관리와 문의 대응까지 포함해 사용자 흐름을 완성했습니다.

주요 기능

  1. 마스크 감지

    VGG16 기반 모델로 마스크 착용 여부를 자동 인식

  2. AI 퍼스널 컬러 진단

    이미지 분석으로 봄/여름/가을/겨울 타입을 분류

  3. 가상 메이크업 시뮬레이션

    BeautyGAN 기반으로 다양한 메이크업 스타일을 적용

  4. 사용자 관리 및 이력 저장

    Redis 기반 인증과 마이페이지 이력 관리 기능 제공

  5. Q&A 게시판

    문의 등록/조회로 사용자 소통과 피드백 흐름 지원

  6. 관리자 기능

    회원 관리와 인증 흐름 보조 기능 제공

향후 개선 방향

이미지 분석 시간이 길어질 때는 요청을 순서대로 처리하는 대기열을 두고, 분석 전 이미지 크기를 줄여 부담을 낮추는 방식으로 응답을 빠르게 하고 싶습니다. 또한 마이페이지에서 같은 사진/조건으로 조회한 결과는 저장해 두었다가 바로 보여주는 방식으로 개선해보고 싶습니다. 마지막으로 Q&A와 마이페이지는 검색·필터와 알림, 히스토리 확인을 보강해 필요한 정보를 더 쉽게 찾도록 개선해보고 싶습니다.

성장 및 배움

오픈소스 모델을 서비스에 연결해 배포와 연동 흐름을 직접 경험했고, UI 총괄을 맡아 화면 구조와 디자인 기준을 잡으면서 사용자 관점에서 일관성을 유지하는 법을 배웠습니다. Q&A·마이페이지는 백엔드까지 포함해 구현하고 관리자 기능도 보조하면서, API 설계와 기능 운영의 감각을 함께 넓힐 수 있었습니다.
